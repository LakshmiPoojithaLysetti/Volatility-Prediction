# 📈 Financial Volatility Prediction using Machine Learning

This project analyzes and predicts **daily market volatility** using a combination of **statistical** and **deep learning** models.  
It explores financial time-series data, performs feature scaling and trend analysis, and evaluates models such as **ARCH**, **GARCH**, and **LSTM neural networks**.

---

## 🚀 Features

- Fetches historical stock data using **Yahoo Finance (yFinance)**
- Computes and visualizes **daily volatility** by month and year
- Performs **train-validation-test splits** for model development
- Implements **ARCH/GARCH** models for volatility estimation
- Builds **LSTM-based neural networks** using TensorFlow
- Includes **hyperparameter tuning** via **Talos**
- Evaluates models using **RMSE and MSE** metrics
- Provides visualizations of **model performance and predictions**
